## What earlier work missed

**The unit of progress drifted toward a cell.** Completion re-closes an accepted answer and retains its receipt. Rule discovery, population staging, and admission are separate operations. A batch can therefore finish without a rule-learning round. The governing epoch needs a reviewed teaching ledger, rule proposals, population consequences, surprise dispositions, and a recomputed residual. A call budget is an execution bound, not a measure of learned structure.

**The curriculum did not expose enough of the representation.** The generated census describes the retained model decisions by bank and sign. It does not judge those decisions wrong. It identifies what variation is available to this particular discovery input. Teaching must deliberately include high-use words, contrasting signs, rule boundaries, and underrepresented banks. Selection should ask which unresolved answer distinguishes plausible mechanisms or unlocks a useful constraint chain. Repeated zeros remain valuable where justified, but their frequency is not evidence that unasked banks are also zero.

**The evidence paths were separated too rigidly.** Source-only discovery correctly prevents a model ruling from becoming a native observation. Reviewed discovery nevertheless needs to combine a native premise with a reviewed target. Version 2 now carries the baseline proof directly and automatically proposes these pairs. Their status stays `OBSERVED_PAIR` until a semantic warrant and independent audit justify more. Legacy input and report formats remain replayable, including the saved monetary-unit and internal-organ admissions.

**Local disagreement encountered an overly strict promotion contract.** The resolver can withdraw a conflicting conditional component and retain another component's conclusion. The population reporter previously dropped all gains for the definition. That reporting behavior is repaired. Admission and migration still require a stricter additive contract: every selected review must agree, and a new conditional exception aborts migration. A proper exception package must name its evidence, scope, retained general rule, dependency changes, and replayed disposition. Removing those checks alone would not implement that package.

**Scope refinement stopped too early.** The saved proposals use narrow WordNet ancestry guards. Those guards make their present scope explicit, but they do not express a general cross-corpus distinction such as a performed action versus a continuing relation. The next learning work is to derive that distinction from complete definitions and existing source/GSE machinery, give it a typed witness, and test it across all evaluable populations. An expanding list of individual exclusions does not by itself establish a reusable mechanism.

**Shared solver code does not finish a candidate transition.** Relational staging now checks the allowed-row consequences that migration can derive. Migration also retires model receipts inside the added rule's scope. A complete migration forecast must simulate that retirement, report reopened cells, and then compare staged and migrated domains. The corpus comparison separately records whether retained model receipts occur on this run's changed definitions.

## The next implementation contract

The controller must consume each reviewed teaching batch, generate bounded proposals, stage their joint effects, and persist the resulting review queue. A reviewed exception must return as a source repair, a specialized condition, an explicit local ruling, or an unresolved question. An admitted revision must trigger candidate migration, full replay, dependent-receipt reconsideration, and fresh curriculum selection. Grounded chain proposals and guard induction should use the existing Regenesis mechanisms through a GSE adapter; the adapter's output must have an actual admission-and-replay consumer.

Joint and conjunctive proposal forms remain necessary. Pairwise observation alone cannot expose every constraint that jointly eliminates alternatives. The resolver already supplies joint support machinery; the proposal grammar, review records, and controller must carry those forms to it. The absence-default contract must continue to distinguish missing evidence from justified orthogonality.

A complete workflow acceptance run should teach a missing bank, derive a reusable rule, apply it to independent definitions, encounter a genuine contradiction, learn and audit a typed refinement, reapply it, and reproduce the final candidate from original evidence and versioned decisions. That full learning-cycle acceptance run has not yet been implemented. The present repairs and population run establish specific prerequisites and expose the remaining connections.

The [reusable workflow](<../../../../rohan-vinaik.github.io/papers/Core Documents/LLM_WORKFLOW/SEMANTIC_CONSTRUCTION_WORKFLOW.md>) records the general procedure and its updated implementation inventory. Release remains conditional on complete justified coverage and validation of the declared cohort. Unknown values and construction checkpoints retain their explicit status throughout the learning process.
