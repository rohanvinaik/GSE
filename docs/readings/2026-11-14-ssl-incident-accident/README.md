The original *accident* sentence describes simultaneous train arrivals in an `it was an accident that …` construction. This names the occurrence but leaves its evaluation unspecified. A chance occurrence and an unfortunate mishap remain possible. Release 014 already assigns HAPPEN=+1 to `incident.n.01`. The exact WordNet gloss of `accident.n.02` defines something that happens suddenly or by chance, supporting HAPPEN=+1 independently of the sentence label. A single typed query audits that open bank.
