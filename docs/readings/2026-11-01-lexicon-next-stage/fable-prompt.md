## Identity and representation

A definition is `(entry_id, lemma, lexical_type, definition, source_ids)`. Native dictionary identities are reused where they identify the intended definition. A new frame, roleset, source record, or grammatical use does not automatically create a new definition. Distinct objects may share geometry: dog and cat need not be geometrically different to remain different lexical identities.

For each ordinary coordinate, the value domain is a nonempty subset of `{-1, 0, +1}`. A singleton is an assignment. Zero means explicitly warranted orthogonality/absence in that coordinate; an unassigned domain means unresolved. Contradiction produces an empty domain and a named CONFLICT outcome, never a vote or a zero. Conflicted entries publish no values.

The existing registries reconcile to 56 ordinary word coordinates, with NUMBER and hierarchy markers treated separately. The representation contract records the ordered basis and its SHA-256 fingerprint. Changes to coordinate meaning, ordering, polarity or hierarchy conventions require an explicit versioned migration and a rebuilt artifact; they must not silently reinterpret a saved artifact.

NUMBER describes the ordinal position of an explicitly named component. It is not a flat coordinate pasted onto every word, and it cannot erase or invert that component's base sign.

## Word and sentence boundary

Word geometry contains the minimal definitional content relevant at word scale. Sentence geometry carries grammatical capabilities, operator scope, argument binding, tense, reference, and the set-theoretic relationships among identified objects. Complete representation across these scales does not require putting every grammatical distinction in the word vector.

THIS has demonstrative object-reference content: the approved lexical anchor is SOMETHING=+1. It does not gain a new THIS coordinate or a HAVE assignment. WHICH object is designated is a grammatical/contextual binding, represented through structured identity. Ownership here must not be conflated with possession: an object's assignment to a grammatical referent is different from asserting that someone possesses it.

At the interface, grammar constrains the permitted roles and bindings. A present but uninstantiated grammatical dimension is distinct from a dimension outside the permitted set. This distinction does not require storing every possible role in the lexical artifact: the active encoder assigns roles dynamically. Set membership, argument ownership, and operator scope operate on structured identities, not vector equality. Two sentences can have similar lexical geometry and different comparison truth conditions.

GSE already implements this separation. `gse/lexicon/pronouns.py` supplies demonstrative reference metadata, `gse/lexicon/function_words.py` supplies determiner metadata, and the symbolic/document paths bind references and represent possession separately. Empty `sentence_primitive_values` tables do not establish missing grammar. The earlier requirement to populate static role masks as a prerequisite to this build was unsupported and is withdrawn.

For versioned dictionaries, the encoder now obtains the established `COMP_METADATA` grammatical operations independently of lexical definition selection. BECAUSE, ONLY and THAN therefore retain their causal, restriction and comparison operations even when the word's lexical lookup is missing or ambiguous. No lexical definition or bank value is manufactured by this bridge. ## Bounded residual model

Only after symbolic closure may an explicitly selected local model receive one unresolved bank. Request version 2 is typed JSON containing the exact definition, source observations, known assignments, every current domain, the approved relation tables and guards, their actual active/blocked/excepted dispositions, and the symbolic proof trace. Output is constrained to the requested bank's surviving ternary values or null. There is no English task prompt, whole-vector fallback, automatic model selection or automatic unlimited budget.

The model-facing scaffold retains the requested bank's full connected relation component, including transitive relations and guard dependencies; disconnected relation/proof material stays in the complete receipt and is declared omitted from the wire view with hashes and counts. All other-bank domains and known values remain visible. Registry coordinate metadata disambiguates the target bank and declares missing polarity definitions rather than inventing them. Protocol and generation identities pin this interpretation. Old version-1 requests remain replayable, but new live calls require the scaffold-bearing format.

Starting with single-question protocol version 6, repeated candidate-definition lists are shared through a reversible codebook. Each list and the expanded evidence view carry hashes; restoration rejects missing, altered, unused, or colliding references. Order and duplicates survive restoration. This reduces repeated wire content without deleting an observation, changing the original full request hash, or increasing the context allowance. Version 7 additionally exposes the existing registry glosses BE = “Stative existence” and EXIST = “Ontological status.” This changes the model protocol pin, not the original saved question, and supplies no new bank assignment or negative pole.

The ruling cannot change known cells or introduce new contradiction exceptions. It is rechecked under the same evidence guards and propagated before acceptance. Abstention, transport failure, malformed data and contradictory output remain distinct outcomes. Model-generated values cannot independently validate their own generating rules. Full residual execution is authorized: every question remains restricted to one currently unresolved bank of one identified definition, rather than requesting a complete representation or changing already justified cells.

Rohan explicitly approved batching bounded word–bank questions on 2026-10-29. `complete --batch-size` groups independently identified questions into one invocation, with at most one pending bank per definition. The next question for that definition is formed only after the preceding answer has passed the existing admission and closure machinery. Batch protocol version 2 binds short response slots to exact full request hashes and refuses missing, duplicated, or additional identities and unrequested bank fields. This avoids generating a long hash for each answer without changing the original request identity. Item and context limits may split a group; they never truncate an item's evidence. A singleton exceeding the context limit receives a named refusal, remains unknown, and does not prevent other definitions from running. Single-item execution remains available.

All dispatched questions receive durable RUNNING journal entries before the batch leaves the process. Answers commit individually with their original full request and proof receipt. An interruption preserves accepted answers and leaves unfinished attempts explicitly recorded; it cannot silently apply an answer after restart. `model_calls` retains its budget meaning of bank questions, while `transport_invocations` separately counts actual dispatches. Batching does not supply semantic justification, equate null with zero, or relax the publication gate.

Operational completion implements a durable request/outcome journal, a fair resumable cursor over eligible residuals, and normalized receipt rows. Each request is tied to an exact definition, one bank and a fresh symbolic state. After any accepted ruling, symbolic closure runs before another request is formed; a resumed attempt must not apply an answer to changed constraints. Budgets bound attempts without repeatedly starving later eligible definitions or disguising unattempted work as abstention. The default three calls per definition is an execution budget, not a completeness rule; an explicit larger bound can cover all remaining coordinates. The report separately measures the selected scope and the whole dictionary. This operational work does not establish causal rule induction or independently validate model answers.

Model execution pins the installed model digest as well as protocol and generation settings. The selected tag is checked around generation; a changed tag invalidates the answer. Output allowance and timeout are explicit bounded settings. Context overflow, exhausted output allowance, transport failure, invalid output, and semantic abstention retain distinct named reasons. Increasing a resource allowance is not permission to change the question's scope or overwrite a known bank.

Both `build` and `complete` expose `--no-thinking`, so the production writer can reproduce a calibrated transport configuration. The protocol's compact evidence view is versioned separately from the retained full source payload. Schema-based omissions carry named reasons and source hashes; context overflow does not authorize silent truncation. A finite authored calibration checks the typed contract and designated examples, not the semantic correctness of every bank or source population.

The explicit `complete --continue-cohorts` mode retains one replay-validated connection for an explicitly budgeted run. Each cohort holds only its bounded source contexts. A temporary candidate-link index supplements the existing exact-entry index; it is rebuilt on restart and never substitutes for replay. External changes invalidate the run. The durable cursor advances across cohorts, and unchanged journaled requests are not repeated indefinitely. Even with `--retry`, a request identity is retried at most once in an invocation; a complete pass with no new attempts stops with `NO_NEW_ATTEMPTS_IN_PASS`. The default one-cohort behavior remains available. This changes execution cost and resumption, not semantic admission or completeness criteria.

`--progress` emits named phase events and committed outcomes without a second database reader. These events do not claim whole-dictionary completion. Receipt storage version 3 deduplicates complete context objects and individual proof records by content hash, preserving proof order and duplicates and reconstructing the original full request for validation. Missing or altered context is refused; deduplication neither drops evidence nor changes the question. Legacy receipts remain readable and migrate transactionally.

## Storage, runtime and verification

The versioned SQLite snapshot separates definitions, published assignments, unresolved domains, source observations, assertions, proof traces, hierarchy, normalized diagnostics, candidate evidence and representation metadata. Large evidence sets are stored as rows rather than one giant JSON value. Rebuilds are transactional; a failed rebuild preserves the earlier snapshot.

Runtime selects explicit definition identities or reports ambiguity. It does not select the first spelling match or merge equal vectors. Published encoding uses warranted values; explicit zero remains in evidence even though it adds no vector signal. Conflicted entries abstain. Exact definition encoding preserves per-component hierarchy signs.

The current entity-coherence resolver is not a lexical-definition selector: it resolves entity type threads downstream and does not update the encoder's token-level lexical definition ID. The versioned voice feature consumer now uses the public encoder's selected lexical evidence rather than caching lemma-only lookups. Completing bank values alone still cannot make every ambiguous content-word lookup readable. Consumers must preserve exact selected definitions and legitimate ambiguity; lexicon completion does not require replacing the wider contextual interpretation architecture or selecting the first dictionary row.

Runtime default-path selection uses `data/lexicon_active.json`, with cache identity tied to the resolved artifact and decoding retaining definition identity rather than merging equal coordinates. Explicitly supplied database paths remain usable for validation. The active pointer is operational state, not a declaration of semantic completeness: the previously activated `replacement.db` is a partial checkpoint and must not be represented as a completed lexicon. The old `lexicon_clean.db` is an archive, not a correctness oracle.

The `publish` command computes release readiness from the full snapshot. It refuses incomplete/conflicted definitions, missing declared words or definitions, an incomplete linked prime foundation, failed replay, unfinished solver searches, and a missing or failing supplied semantic audit. The audit must exercise every ordinary coordinate; its results establish correctness only for its supplied labels. Publication copies the candidate to a new database, revalidates the copy, records its digest, and atomically switches the pointer. A failure leaves the previous pointer intact. Publication never interprets omitted rows as zero. The full independent frequency/text-coverage and omission audits remain obligations beyond a small supplied-label audit; the command does not claim those audits have occurred.

Validation replays the snapshot read-only, checking source provenance, metadata, domains, assignments, guard decisions and model receipts. Semantic evaluation separately uses independently supplied labels and reports correct/abstained/conflicted/wrong/not-found by bank, lexical type and source cohort. Replay success is not semantic gold. Reports state metadata reconstruction limits.

The symbolic proof runner now distinguishes PASSED, FAILED, and ABSTAINED. Its bipolar geometry comparison requires selected lexical evidence and a nonempty evaluation bank before computing cosine; missing, ambiguous, unknown, and explicit-zero inputs do not become numerical counterexamples or passes. The command returns nonzero for either failures or abstentions. Explicit synthetic mechanism fixtures exercise signed degree, negation, and lemma invariance independently of the active corpus, while separate tests preserve refusal on ambiguous complete definitions. These fixtures are not semantic gold for publication.

Runtime anchor isolation checks provenance rather than requiring unanchored cells to remain unknown forever. A separately justified zero in THIS/HAVE is compatible with object reference; possession or its negation is not supplied by that reference. Other VERY definitions may acquire independently justified values, but must not receive the two approved ordinal anchors by spelling. These finite checks do not replace full replay or independent semantic evaluation.

Comparing against it can expose migration changes, but agreement with it is not proof of correctness and disagreement is not automatically a regression.

def _fields(record, required, optional=()):
    if type(record) is not dict or not set(required) <= record.keys() or record.keys() - set(required) - set(optional):
        raise ValueError("INVALID_PATTERN_INPUT_FIELDS")


def _ids(values: list[str]):
    if type(values) is not list or any(type(value) is not str or not value.strip() for value in values):
        raise ValueError("INVALID_PATTERN_ENTRY_IDS")
    if len(set(values)) != len(values):
        raise ValueError("DUPLICATE_PATTERN_ENTRY_ID")
    return tuple(sorted(values))


def reviewed_rulings(records: list[dict]) -> tuple[ReviewedRuling, ...]:
    """Validate explicitly accepted reviews without upgrading model provenance."""
    if type(records) is not list:
        raise ValueError("INVALID_REVIEWED_RULINGS")
    result, seen = [], set()
    for record in records:
        _fields(record, ("receipt", "review"))
        receipt = validate_receipt(record["receipt"])
        review = record["review"]
        _fields(review, ("review_id", "reviewer", "receipt_sha256", "code"))
        if review["code"] != "ACCEPTED" or any(
            type(review[key]) is not str or not review[key].strip() for key in ("review_id", "reviewer")
        ):
            raise ValueError("RULING_REQUIRES_EXPLICIT_REVIEW")
        digest = _request_id(receipt)
        if review["receipt_sha256"] != digest:
            raise ValueError("STALE_RULING_REVIEW")
        payload, assertion = receipt["request"], Assertion(**receipt["assertion"])
        model_input(payload)  # The real wire contract validates definition, scaffold, and typed domains.
        bank = payload["bank"]
        schema = {
            "type": "object",
            "properties": {bank: {"type": ["integer", "null"], "enum": [*payload["allowed_values"], None]}},
            "required": [bank],
            "additionalProperties": False,
        }
        if (
            receipt["entry_id"] != payload["entry_id"]
            or receipt["request_id"] != _request_id(payload)
            or assertion.bank != bank
            or assertion.value not in payload["allowed_values"]
            or bank in payload["known"]
            or _canonical_json(receipt["schema"]) != _canonical_json(schema)
        ):
            raise ValueError("REVIEWED_RULING_REQUEST_MISMATCH")
        if receipt["request_id"] in seen:
            raise ValueError("DUPLICATE_REVIEWED_REQUEST")
        seen.add(receipt["request_id"])
        result.append(
            ReviewedRuling(
                receipt["entry_id"],
                bank,
                assertion.value,
                receipt["request_id"],
                assertion.source,
                review["review_id"],
                review["reviewer"],
                digest,
                receipt,
            )
        )
    return tuple(sorted(result, key=lambda row: (row.entry_id, row.bank, row.request_id)))


def _ruling_reference(row):
    return {key: value for key, value in asdict(row).items() if key != "receipt"}


def propose_patterns(rulings, *, discovery_entry_ids, audit_entry_ids, candidates=None) -> tuple[Pattern, ...]:
    """Observe pair implications; never use counts to approve a lexical rule."""
    discovery, audit = _ids(discovery_entry_ids), _ids(audit_entry_ids)
    if set(discovery) & set(audit):
        raise ValueError("DISCOVERY_AUDIT_ID_OVERLAP")
    grouped = {entry: defaultdict(list) for entry in discovery}
    for row in rulings:
        if row.entry_id in grouped:
            grouped[row.entry_id][row.bank].append(row)
    generated = set()
    if candidates is None:
        for banks in grouped.values():
            singletons = [
                (bank, next(iter(values)))
                for bank, rows in banks.items()
                if len(values := {row.value for row in rows}) == 1
            ]
            generated.update((*left, *right) for left, right in permutations(singletons, 2))
    else:
        if type(candidates) is not list:
            raise ValueError("INVALID_PATTERN_CANDIDATES")
        for candidate in candidates:
            if (
                type(candidate) is not list
                or len(candidate) != 4
                or any(type(candidate[i]) is not str or candidate[i] not in BANKS for i in (0, 2))
                or candidate[0] == candidate[2]
                or any(type(candidate[i]) is not int or candidate[i] not in (-1, 0, 1) for i in (1, 3))
            ):
                raise ValueError("INVALID_PATTERN_CANDIDATE")
            generated.add(tuple(candidate))
    patterns = []
    for left, a, right, b in sorted(generated):
        records = []
        for entry, banks in grouped.items():
            left_values = {row.value for row in banks[left]}
            right_values = {row.value for row in banks[right]}
            code = (
                "ANTECEDENT_CONFLICT"
                if len(left_values) > 1
                else "ANTECEDENT_UNKNOWN"
                if not left_values
                else "PREMISE_NOT_MET"
                if left_values != {a}
                else "CONSEQUENT_CONFLICT"
                if len(right_values) > 1
                else "CONSEQUENT_UNKNOWN"
                if not right_values
                else "OBSERVED_AGREEMENT"
                if right_values == {b}
                else "OBSERVED_COUNTEREXAMPLE"
            )
            records.append(
                {
                    "entry_id": entry,
                    "code": code,
                    "rulings": [_ruling_reference(row) for row in banks[left] + banks[right]],
                }
            )
        provenance = tuple(
            sorted(
                {
                    f"review:{row.review_id}:{row.receipt_sha256}"
                    for row in rulings
                    if row.entry_id in discovery and row.bank in (left, right)
                }
            )
        )
        rule = Relation(
            "reviewed-pattern:" + _request_id({"antecedent": [left, a], "consequent": [right, b]}),
            (left, right),
            tuple((x, y) for x in (-1, 0, 1) for y in (-1, 0, 1) if x != a or y == b),
            provenance,
            authority="conditional",
            approved=False,
        )
        patterns.append(Pattern(rule, (left, a), (right, b), discovery, audit, tuple(records)))
    return tuple(patterns)


def _relation(record):
    _fields(
        record,
        ("rule_id", "banks", "allowed_rows", "provenance"),
        ("authority", "approved", "guards", "absent_evidence"),
    )
    result = dict(record)
    for name in ("banks", "allowed_rows", "provenance", "guards", "absent_evidence"):
        if name not in result:
            continue
        if type(result[name]) is not list:
            raise ValueError("INVALID_PATTERN_RELATION")
        if name in {"allowed_rows", "guards"} and any(type(value) is not list for value in result[name]):
            raise ValueError("INVALID_PATTERN_RELATION_ROW")
        result[name] = (
            tuple(tuple(value) for value in result[name]) if name in {"allowed_rows", "guards"} else tuple(result[name])
        )
    return Relation(**result)


def _definition_input(raw):
    _fields(raw, ("definition", "assertions", "anchors", "observations", "domain_restrictions", "context"))
    _fields(raw["definition"], ("entry_id", "lemma", "pos", "definition"), ("source_ids",))
    definition_data = dict(raw["definition"])
    source_ids = definition_data.get("source_ids", [])
    _ids(source_ids)
    definition_data["source_ids"] = tuple(source_ids)
    definition = Definition(**definition_data)
    if raw["context"] != definition_context(definition.pos):
        raise ValueError("UNSUPPORTED_PATTERN_CONTEXT")
    for key in ("assertions", "anchors", "observations", "domain_restrictions"):
        if type(raw[key]) is not list:
            raise ValueError("INVALID_PATTERN_INPUT_SEQUENCE")
    observations, links, relevance = [], {}, set()
    for record in raw["observations"]:
        _fields(record, ("entry_id", "source", "record_id", "family", "features", "scope"), ("candidate_entry_ids",))
        native = dict(record)
        candidates = native.get("candidate_entry_ids", [])
        _ids(candidates)
        native["candidate_entry_ids"] = tuple(candidates)
        observation = Observation(**native)
        if observation.source.startswith(("model:", "rule:", "derived:")) or observation.family in {"model", "derived"}:
            raise ValueError("UNSUPPORTED_PRIOR_MODEL_OR_DERIVED_BASELINE")
        targets = (observation.entry_id,) if observation.entry_id is not None else observation.candidate_entry_ids
        if definition.entry_id not in targets:
            raise ValueError("PATTERN_SOURCE_DEFINITION_MISMATCH")
        key = (observation.source, observation.record_id)
        if key in links:
            raise ValueError("DUPLICATE_PATTERN_SOURCE_RECORD")
        links[key] = observation
        relevance.update(observation_relevance(observation))
        observations.append(asdict(observation))
    assertions, restrictions = [], []
    for kind in ("assertions", "anchors", "domain_restrictions"):
        for record in raw[kind]:
            coordinate = "allowed_values" if kind == "domain_restrictions" else "value"
            _fields(record, ("bank", coordinate, "source", "record_id", "family"), ("scope",))
            item = dict(record)
            if kind == "domain_restrictions":
                if type(item["allowed_values"]) is not list:
                    raise ValueError("INVALID_PATTERN_RESTRICTION_VALUES")
                item["allowed_values"] = tuple(item["allowed_values"])
                value = DomainRestriction(**item)
            else:
                value = Assertion(**item)
            if value.source.startswith(("model:", "rule:", "derived:")) or value.family in {"model", "derived"}:
                raise ValueError("UNSUPPORTED_PRIOR_MODEL_OR_DERIVED_BASELINE")
            validate_assertion_competence(value)
            if kind != "anchors":
                link = links.get((value.source, value.record_id))
                if (
                    link is None
                    or link.entry_id != definition.entry_id
                    or link.scope != "lexical"
                    or link.family != value.family
                ):
                    raise ValueError("PATTERN_ASSERTION_PROVENANCE_MISMATCH")
            (restrictions if kind == "domain_restrictions" else assertions).append(value)
    return DefinitionInput(
        definition,
        tuple(assertions),
        tuple(observations),
        tuple(restrictions),
        dict(raw["context"]),
        tuple(sorted(relevance)),
    )


def _same_table(left, right):
    if set(left.banks) != set(right.banks):
        return False
    order = tuple(right.banks.index(bank) for bank in left.banks)
    return set(left.allowed_rows) == {tuple(row[i] for i in order) for row in right.allowed_rows}


def _baseline(pattern, entry, relations):
    if any(rule.rule_id == pattern.relation.rule_id or _same_table(pattern.relation, rule) for rule in relations):
        raise ValueError("TESTED_RULE_PRESENT_IN_BASELINE")
    return resolve_dictionary(
        BANKS,
        entry.assertions,
        relations,
        entry.context,
        evidence_banks=entry.evidence_banks,
        domain_restrictions=entry.restrictions,
    )


def _antecedent_state(pattern, entry, relations, rulings):
    baseline = _baseline(pattern, entry, relations)
    left, expected = pattern.antecedent
    if baseline.code == "CONFLICT":
        return baseline, entry.assertions, "BASELINE_CONFLICT"
    if left in baseline.assignments:
        return baseline, entry.assertions, "READY" if baseline.assignments[left] == expected else "PREMISE_NOT_MET"
    relevant = [row for row in rulings if row.entry_id == entry.definition.entry_id and row.bank == left]
    if not relevant:
        return baseline, entry.assertions, "ANTECEDENT_UNKNOWN"
    if len({row.value for row in relevant}) != 1:
        return baseline, entry.assertions, "ANTECEDENT_CONFLICT"
    if relevant[0].value != expected:
        return baseline, entry.assertions, "PREMISE_NOT_MET"
    # Every supplied antecedent receipt must replay from the same native/anchor
    # baseline. This deliberately refuses unsupported earlier-model DAGs.
    for row in relevant:
        payload = row.receipt["request"]
        if pattern.consequent[0] in payload["known"]:
            return baseline, entry.assertions, "TARGET_LEAKAGE_IN_ANTECEDENT_REQUEST"
        if any(
            record.get("kind") == "ASSERTION"
            and (record.get("family") == "model" or str(record.get("source", "")).startswith("model:"))
            for record in payload["scaffold"]["proof_trace"]
        ):
            return baseline, entry.assertions, "UNSUPPORTED_PRIOR_MODEL_DEPENDENCY"
        fresh = build_request(
            entry.definition.entry_id,
            left,
            baseline,
            entry.observations,
            definition=entry.definition,
            relations=relations,
            context=entry.context,
        )
        if fresh.request_id != row.request_id:
            return baseline, entry.assertions, "ANTECEDENT_BASELINE_MISMATCH"
    row = relevant[0]
    replay = complete_bank(
        fresh,
        BANKS,
        entry.assertions,
        relations,
        _ReviewedAnswer(row),
        entry.context,
        evidence_banks=entry.evidence_banks,
        domain_restrictions=entry.restrictions,
    )
    if replay.code != "ASSIGNED" or replay.assertion is None or replay.resolution is None:
        return baseline, entry.assertions, "ANTECEDENT_CONTRADICTION"
    return replay.resolution, entry.assertions + (replay.assertion,), "READY"


class _ReviewedAnswer:
    """Replay a pinned accepted answer through the ordinary acceptance checks."""

    def __init__(self, ruling):
        self.identity = ruling.source.removeprefix("model:")
        self.raw = _canonical_json({ruling.bank: ruling.value})

    def __call__(self, payload, schema):
        return self.raw


def stage_pattern(pattern, entry, relations, rulings):
    """Temporarily test one conditional relation; return no approved relation."""
    baseline, assertions, code = _antecedent_state(pattern, entry, relations, rulings)
    result = {"entry_id": entry.definition.entry_id, "code": code, "writes": False}
    if code != "READY":
        return result
    if not pattern.relation.provenance:
        return {**result, "code": "NO_REVIEWED_PATTERN_PROVENANCE"}
    staged = resolve_dictionary(
        BANKS,
        assertions,
        relations + (replace(pattern.relation, approved=True),),
        entry.context,
        evidence_banks=entry.evidence_banks,
        domain_restrictions=entry.restrictions,
    )
    previous = [record for record in baseline.trace if record["kind"] == "CONDITIONAL_EXCEPTION"]
    previous_keys = {_canonical_json(record) for record in previous}
    exceptions = [
        record
        for record in staged.trace
        if record["kind"] == "CONDITIONAL_EXCEPTION" and _canonical_json(record) not in previous_keys
    ]
    return {
        **result,
        "code": "STAGED_CONFLICT" if staged.code == "CONFLICT" else "STAGED_EXCEPTION" if exceptions else "STAGED_ONLY",
        "changed_domains": {
            bank: {"before": sorted(baseline.domains[bank]), "after": sorted(domain)}
            for bank, domain in staged.domains.items()
            if domain != baseline.domains[bank]
        },
        "conditional_exceptions": exceptions,
        "baseline_conditional_exceptions": previous,
        "conflicts": staged.conflicts,
        "production_rule_approved": False,
    }


class _CapturedTransport:
    def __init__(self, transport):
        self.transport, self.identity, self.raw = transport, transport.identity, None
        self.calls = 0

    def __call__(self, payload, schema):
        self.calls += 1
        self.raw = self.transport(payload, schema)
        return self.raw


def audit_pattern(pattern, entry, relations, rulings, transport=None, *, allow_call=False):
    """Ask only the withheld target using baseline closure, never staged answers."""
    if entry.definition.entry_id not in pattern.audit_entry_ids:
        raise ValueError("AUDIT_DEFINITION_NOT_HELD_OUT")
    baseline, assertions, code = _antecedent_state(pattern, entry, relations, rulings)
    result = {
        "entry_id": entry.definition.entry_id,
        "bank": pattern.consequent[0],
        "code": code,
        "model_calls": 0,
        "comparison_authority": "UNAPPROVED_PATTERN_NOT_GOLD",
    }
    if code != "READY":
        return result
    bank, expected = pattern.consequent
    if bank in baseline.assignments:
        return {**result, "code": "SYMBOLICALLY_RESOLVED_PREEXISTING", "value": baseline.assignments[bank]}
    request = build_request(
        entry.definition.entry_id,
        bank,
        baseline,
        entry.observations,
        definition=entry.definition,
        relations=relations,
        context=entry.context,
    )
    result.update(request=request.payload(), schema=request.output_schema(), request_id=request.request_id)
    if not allow_call or transport is None:
        return {**result, "code": "AUDIT_CALL_BUDGET_EXHAUSTED"}
    captured = _CapturedTransport(transport)
    completion = complete_bank(
        request,
        BANKS,
        assertions,
        relations,
        captured,
        entry.context,
        evidence_banks=entry.evidence_banks,
        domain_restrictions=entry.restrictions,
    )
    if completion.code == "ASSIGNED":
        assert completion.assertion is not None
        value = completion.assertion.value
        code = "MODEL_AGREEMENT" if value == expected else "MODEL_COUNTEREXAMPLE"
        result["value"] = value
    else:
        code = {"ABSTAINED": "MODEL_ABSTAINED", "CONTRADICTION": "MODEL_CONFLICT"}.get(completion.code, completion.code)
    return {
        **result,
        "code": code,
        "model_calls": captured.calls,
        "details": completion.details,
        "raw_output": captured.raw,
        "transport_identity": captured.identity,
        "proposed_value": expected,
        "writes": False,
    }


def run_workflow(path: str | Path, transport=None, *, max_calls=0):
    """Strict file-based proposal/staging/audit; never opens a lexicon database."""
    if type(max_calls) is not int or max_calls < 0:
        raise ValueError("INVALID_PATTERN_CALL_BUDGET")
    raw = read_json(path)
    _fields(
        raw, ("format", "rulings", "discovery_entry_ids", "audit_entry_ids", "entries", "relations"), ("candidates",)
    )
    if raw["format"] != INPUT_FORMAT or type(raw["entries"]) is not list or type(raw["relations"]) is not list:
        raise ValueError("INVALID_PATTERN_INPUT_FORMAT")
    rulings = reviewed_rulings(raw["rulings"])
    entries = {}
    for record in raw["entries"]:
        entry = _definition_input(record)
        if entry.definition.entry_id in entries:
            raise ValueError("DUPLICATE_PATTERN_DEFINITION")
        entries[entry.definition.entry_id] = entry
    relations = tuple(_relation(record) for record in raw["relations"])
    patterns = propose_patterns(
        rulings,
        discovery_entry_ids=raw["discovery_entry_ids"],
        audit_entry_ids=raw["audit_entry_ids"],
        candidates=raw.get("candidates"),
    )
    requested = set(raw["discovery_entry_ids"]) | set(raw["audit_entry_ids"])
    if not requested <= entries.keys() or any(row.entry_id not in requested for row in rulings):
        raise ValueError("UNKNOWN_PATTERN_DEFINITION")
    for row in rulings:
        definition = entries[row.entry_id].definition
        exact = {key: getattr(definition, key) for key in ("entry_id", "lemma", "pos", "definition")}
        if row.receipt["request"]["definition"] != exact:
            raise ValueError("REVIEWED_RULING_DEFINITION_MISMATCH")
    for entry in entries.values():
        resolve_dictionary(
            BANKS,
            entry.assertions,
            relations,
            entry.context,
            evidence_banks=entry.evidence_banks,
            domain_restrictions=entry.restrictions,
        )
    calls, reports = 0, []
    for pattern in patterns:
        stages, audits = [], []
        for entry_id in pattern.audit_entry_ids:
            entry = entries[entry_id]
            stages.append(stage_pattern(pattern, entry, relations, rulings))
            audit = audit_pattern(pattern, entry, relations, rulings, transport, allow_call=calls < max_calls)
            calls += audit["model_calls"]
            audits.append(audit)
        reports.append(
            {
                "relation": asdict(pattern.relation),
                "antecedent": pattern.antecedent,
                "consequent": pattern.consequent,
                "discovery": pattern.records,
                "discovery_outcomes": dict(Counter(record["code"] for record in pattern.records)),
                "staging": stages,
                "audits": audits,
                "audit_outcomes": dict(Counter(record["code"] for record in audits)),
                "admission": "UNAPPROVED_CANDIDATE",
            }
        )
    audit_requests = defaultdict(list)
    for report in reports:
        for audit in report["audits"]:
            if "request_id" in audit:
                audit_requests[audit["request_id"]].append((report["relation"]["rule_id"], audit["model_calls"]))
    return {
        "format": REPORT_FORMAT,
        "input_sha256": _request_id(raw),
        "model_calls": calls,
        "max_model_calls": max_calls,
        "discovery_entry_ids": raw["discovery_entry_ids"],
        "audit_entry_ids": raw["audit_entry_ids"],
        "candidates": reports,
        "repeated_audit_requests": [
            {
                "code": "REPEATED_AUDIT_REQUEST",
                "request_id": request_id,
                "candidate_rule_ids": [rule for rule, _ in items],
                "evaluations": len(items),
                "model_calls": sum(calls for _, calls in items),
            }
            for request_id, items in sorted(audit_requests.items())
            if len(items) > 1
        ],
        "lexicon_writes": False,
        "authority": "EXPLICIT_REVIEWED_MODEL_RULINGS_NOT_NATIVE_SOURCE_OR_INDEPENDENT_GOLD",
        "unsupported": [
            "PRIOR_MODEL_DEPENDENCY_DAGS",
            "CONTEXT_BEYOND_DEFINITION_POS",
            "AUTOMATIC_RULE_PROMOTION",
            "PRODUCTION_RULE_REPLAY_MIGRATION",
        ],
    }

def _model_scope_audit(conn: sqlite3.Connection) -> dict:
    """Audit active rulings under current scope rules, independently of completeness.

    Withdrawn receipts remain historical evidence in their archive and are not
    active assertions. NOT_APPLICABLE means this narrow check has no verdict;
    it never substitutes for replay or independent semantic evaluation.
    """
    records, outcomes = [], Counter()
    try:
        receipts = read_model_receipts(conn)
        for entry_id in sorted(receipts):
            for receipt in receipts[entry_id]:
                assertion = receipt["assertion"]
                observations = receipt["request"].get("observations")
                if not isinstance(observations, list) or any(not isinstance(row, dict) for row in observations):
                    raise ValueError("INVALID_MODEL_REQUEST_OBSERVATIONS")
                admission = model_scope_admission(entry_id, assertion["bank"], assertion["value"], observations)
                outcomes[admission["code"]] += 1
                records.append(
                    {
                        "entry_id": entry_id,
                        "request_id": receipt["request_id"],
                        "bank": assertion["bank"],
                        "value": assertion["value"],
                        "source": assertion["source"],
                        "admission": admission,
                    }
                )
    except (ValueError, TypeError, KeyError, sqlite3.Error) as error:
        return {
            "code": "INVALID_MODEL_RECEIPT",
            "reason": str(error),
            "outcomes": dict(outcomes),
            "records": records,
            "scope": "ACTIVE_MODEL_RECEIPTS_ONLY",
            "not_applicable_is_semantic_approval": False,
        }
    return {
        "code": "SCOPE_UNJUSTIFIED" if outcomes["SCOPE_UNJUSTIFIED"] else "NO_SCOPE_REJECTION",
        "outcomes": dict(outcomes),
        "records": records,
        "scope": "ACTIVE_MODEL_RECEIPTS_ONLY",
        "not_applicable_is_semantic_approval": False,
    }


def publication_readiness(path: str | Path, gold_path: str | Path | None = None) -> dict:
    """Compute whole-snapshot completeness; a successful replay alone is insufficient.

    Gold evaluation is scoped to the supplied labels, never described as proof
    of every unlabelled cell. Every coordinate must be represented in that audit.
    Neither a smaller worklist nor deletion of a difficult sense can turn a
    checkpoint into a complete release.
    """
    file = Path(path).expanduser().resolve()
    if not file.is_file():
        raise ValueError("BUILD_NOT_FOUND")
    blockers, cells, outcomes = [], Counter(), Counter()
    with closing(sqlite3.connect(file.as_uri() + "?mode=ro", uri=True)) as conn:
        conn.execute("BEGIN")
        if _metadata(conn, "format") != VERSION:
            raise ValueError("UNSUPPORTED_BUILD_FORMAT")
        if _metadata(conn, "representation_contract") != representation_contract():
            blockers.append("REPRESENTATION_CONTRACT_MISMATCH")
        words = _metadata(conn, "requested_words")
        requested_ids = _metadata(conn, "requested_definition_ids")
        if not isinstance(words, list) or not words or any(not isinstance(w, str) or not w for w in words):
            blockers.append("MISSING_DECLARED_WORD_COHORT")
            words = []
        cohort_known = True
        if (
            not isinstance(requested_ids, list)
            or not requested_ids
            or any(not isinstance(i, str) or not i for i in requested_ids)
        ):
            blockers.append("MISSING_DECLARED_DEFINITION_COHORT")
            cohort_known = False
            requested_ids = []
        states = {}
        for entry_id, code, payload in conn.execute("SELECT entry_id,code,domains FROM definition_states"):
            if entry_id in states:
                blockers.append("DUPLICATE_DEFINITION_ID")
            states[entry_id] = code
            outcomes[code] += 1
            domains = _read_json(payload)
            if not isinstance(domains, dict) or set(domains) != set(BANKS):
                blockers.append("INVALID_DOMAIN_BASIS")
                continue
            for domain in domains.values():
                if (
                    not isinstance(domain, list)
                    or any(type(v) is not int or v not in {-1, 0, 1} for v in domain)
                    or len(set(domain)) != len(domain)
                ):
                    blockers.append("INVALID_DOMAIN_VALUES")
                elif not domain:
                    cells["conflicted"] += 1
                elif len(domain) > 1:
                    cells["unresolved"] += 1
                else:
                    cells["assigned"] += 1
                    cells["explicit_zero"] += domain == [0]
        present_words = {row[0].strip().lower() for row in conn.execute("SELECT lemma FROM lexemes")}
        missing_words = sorted(set(words) - present_words)
        missing_ids = sorted(set(requested_ids) - states.keys()) if cohort_known else []
        extra_ids = sorted(states.keys() - set(requested_ids)) if cohort_known else []
        if missing_words:
            blockers.append("REQUESTED_WORDS_MISSING")
        if missing_ids or extra_ids:
            blockers.append("DEFINITION_COHORT_MISMATCH")
        if not states:
            blockers.append("EMPTY_BUILD")
        if cells["unresolved"] or cells["conflicted"] or set(outcomes) - {"RESOLVED"}:
            blockers.append("INCOMPLETE_DEFINITIONS")
        prime_entries = _metadata(conn, "prime_entries")
        from .catalog import catalog_inventory

        units = {unit["unit_id"] for unit in catalog_inventory()["units"]}
        linked = prime_entries if isinstance(prime_entries, dict) else {}
        unlinked_units = sorted(unit for unit in units if not linked.get(unit))
        if unlinked_units or any(
            not isinstance(ids, list) or any(states.get(entry) != "RESOLVED" for entry in ids)
            for ids in linked.values()
        ):
            blockers.append("INCOMPLETE_PRIME_FOUNDATION")
        model_scope = _model_scope_audit(conn)
        if model_scope["outcomes"].get("SCOPE_UNJUSTIFIED"):
            blockers.append("MODEL_SCOPE_UNJUSTIFIED")
        if model_scope["code"] == "INVALID_MODEL_RECEIPT":
            blockers.append("MODEL_SCOPE_AUDIT_INVALID_RECEIPT")
    # A failed completeness check needs no expensive replay to refuse promotion.
    replay = {"code": "NOT_RUN_INCOMPLETE_CANDIDATE"}
    if not blockers:
        replay = validate_build(file)
        if replay["code"] != "REPLAY_VALIDATED":
            blockers.append("REPLAY_FAILED")
        if not replay.get("complete_search", False):
            blockers.append("SOLVER_SEARCH_INCOMPLETE")
    gold = {"code": "NOT_SUPPLIED"}
    if gold_path is None:
        blockers.append("SEMANTIC_AUDIT_NOT_SUPPLIED")
    elif not blockers:
        gold = evaluate_build(file, gold_path)
        if any(count for code, count in gold["outcomes"].items() if code != "IDENTIFIED_CORRECT"):
            blockers.append("SEMANTIC_AUDIT_FAILURE")
        if set(gold["per_bank"]) != set(BANKS):
            blockers.append("SEMANTIC_AUDIT_MISSING_COORDINATES")
    else:
        gold = {"code": "NOT_RUN_INCOMPLETE_CANDIDATE", "path": str(Path(gold_path).resolve())}
    return {
        "format": "gse.lexicon-publication-audit/1",
        "code": "READY_FOR_PUBLICATION" if not blockers else "PUBLICATION_BLOCKED",
        "blockers": sorted(set(blockers)),
        "definitions": len(states),
        "outcomes": dict(outcomes),
        "cells": dict(cells),
        "missing_words": missing_words,
        "missing_definition_ids": missing_ids,
        "unexpected_definition_ids": extra_ids,
        "definition_cohort": "DECLARED" if cohort_known else "NOT_RECORDED",
        "unlinked_prime_units": unlinked_units,
        "replay": replay,
        "semantic_audit": gold,
        "semantic_audit_scope": "SUPPLIED_LABELS_NOT_A_PROOF_OF_UNLABELLED_CELLS",
        "model_scope_audit": model_scope,
    }


def publish_complete(
    path: str | Path, destination: str | Path, gold_path: str | Path, *, pointer_path: str | Path = ACTIVE_POINTER
) -> dict:
    """Publish an immutable copy; failed validation never changes the active pointer."""
    source, destination, pointer = (Path(p).expanduser().resolve() for p in (path, destination, pointer_path))
    if not source.is_file():
        raise ValueError("BUILD_NOT_FOUND")
    if source == destination or destination.exists() or pointer in {source, destination}:
        raise ValueError("PUBLICATION_REQUIRES_NEW_DESTINATION")
    # Fail cheaply without copying a multi-GB incomplete checkpoint.
    readiness = publication_readiness(source, gold_path)
    if readiness["code"] != "READY_FOR_PUBLICATION":
        return readiness
    destination.parent.mkdir(parents=True, exist_ok=True)
    descriptor, filename = tempfile.mkstemp(prefix=".lexicon-release-", suffix=".db", dir=destination.parent)
    os.close(descriptor)
    temporary = Path(filename)
    pointer_temp = None
    try:
        with closing(sqlite3.connect(source.as_uri() + "?mode=ro", uri=True)) as incoming:
            with closing(sqlite3.connect(temporary)) as outgoing:
                incoming.backup(outgoing)
        # Validate the copy actually being published, including any intervening changes.
        readiness = publication_readiness(temporary, gold_path)
        if readiness["code"] != "READY_FOR_PUBLICATION":
            return readiness
        with temporary.open("rb") as stream:
            os.fsync(stream.fileno())
            digest = hashlib.file_digest(stream, "sha256").hexdigest()
        # Link without replacement: never clobber another publication's destination.
        os.link(temporary, destination)
        pointer.parent.mkdir(parents=True, exist_ok=True)
        descriptor, filename = tempfile.mkstemp(prefix=".lexicon-active-", suffix=".json", dir=pointer.parent)
        pointer_temp = Path(filename)
        payload = {"format": POINTER_FORMAT, "path": os.path.relpath(destination, pointer.parent)}
        with os.fdopen(descriptor, "w") as stream:
            stream.write(json.dumps(payload, sort_keys=True) + "\n")
            stream.flush()
            os.fsync(stream.fileno())
        os.replace(pointer_temp, pointer)
        return {**readiness, "code": "PUBLISHED_COMPLETE_LEXICON", "path": str(destination), "sha256": digest}
    finally:
        temporary.unlink(missing_ok=True)
        if pointer_temp is not None:
            pointer_temp.unlink(missing_ok=True)

"""Source-typed checks on model rulings; these checks never supply bank values."""

from __future__ import annotations

import json
from dataclasses import asdict

REFERENCE_COMPONENTS = frozenset({"I", "YOU", "SOMEONE", "SOMETHING", "PEOPLE", "SAME"})
BE_SCOPE_SOURCE = "docs/program/LEXICON_CONSTRUCTION_DESIGN.md#be-stative-content-scope"


def _catalog_reference_record(entry_id: str, record: dict) -> str:
    """Recognize a complete existing native row, not a label or a spelling."""
    from gse.curation.external_sources.gse_closed_class import GSEClosedClassParser

    if record.get("source") != "gse_closed_class" or record.get("family") != "gse_curated_grammar":
        return "ADDITIONAL_EXACT_LEXICAL_SOURCE"
    features = record.get("features")
    if type(features) is not dict:
        return "UNRECOGNIZED_NATIVE_CATALOG_RECORD"
    if features.get("catalog") != "pronoun" or features.get("grammar_roles") != ["PRON"]:
        return "NOT_NATIVE_PRONOUN_REFERENCE_ROLE"
    components = features.get("primitives")
    if type(components) is not dict or not components:
        return "NO_DECLARED_REFERENCE_COMPONENT"
    if any(type(name) is not str or name not in REFERENCE_COMPONENTS for name in components):
        return "NONREFERENCE_LEXICAL_COMPONENT"
    lemma = features.get("lemma")
    if type(lemma) is not str or not lemma:
        return "UNRECOGNIZED_NATIVE_CATALOG_RECORD"
    # Lookup identifies a source record for equality verification, never a
    # spelling-based semantic assignment. Every native field must match.
    for entry in GSEClosedClassParser().get_entries(lemma):
        if entry.entry_id != entry_id:
            continue
        native = json.loads(json.dumps(asdict(entry), allow_nan=False))
        try:
            actual = json.dumps(features, sort_keys=True, allow_nan=False)
            expected = json.dumps(native, sort_keys=True, allow_nan=False)
        except TypeError, ValueError:
            return "UNRECOGNIZED_NATIVE_CATALOG_RECORD"
        if actual == expected:
            return "EXACT_NATIVE_REFERENCE_ONLY_CATALOG"
    return "UNRECOGNIZED_NATIVE_CATALOG_RECORD"


def model_scope_admission(
    entry_id: str, bank: str, value: int | None, observations: tuple[dict, ...] | list[dict]
) -> dict:
    """Refuse positive BE supported only by the exact native reference catalog.

    Association/world records cannot supply own-word stative content. An
    additional exact lexical source or a different native catalog component
    prevents the narrow reference-only classification. NOT_APPLICABLE is not
    approval: the ordinary freshness, domain and contradiction checks still
    govern the ruling. Zero, negative signs and null receive no new value here.
    """
    if bank != "BE" or type(value) is not int or value != 1:
        return {"code": "NOT_APPLICABLE", "reason": "OUTSIDE_POSITIVE_BE_SCOPE_CHECK"}
    if type(entry_id) is not str or not entry_id or type(observations) not in (tuple, list):
        return {"code": "NOT_APPLICABLE", "reason": "UNCLASSIFIED_SOURCE_INPUT"}
    if any(type(record) is not dict for record in observations):
        return {"code": "NOT_APPLICABLE", "reason": "UNCLASSIFIED_SOURCE_INPUT"}
    exact = [
        record for record in observations if record.get("entry_id") == entry_id and record.get("scope") == "lexical"
    ]
    if not exact:
        return {"code": "NOT_APPLICABLE", "reason": "NO_EXACT_LEXICAL_SOURCE"}
    witnesses = []
    for record in exact:
        code = _catalog_reference_record(entry_id, record)
        if code != "EXACT_NATIVE_REFERENCE_ONLY_CATALOG":
            return {"code": "NOT_APPLICABLE", "reason": code}
        record_id = record.get("record_id")
        if type(record_id) is not str or not record_id:
            return {"code": "NOT_APPLICABLE", "reason": "UNRECOGNIZED_NATIVE_CATALOG_RECORD"}
        witnesses.append(record_id)
    return {
        "code": "SCOPE_UNJUSTIFIED",
        "reason": "ENTITY_REFERENCE_ALONE_DOES_NOT_JUSTIFY_POSITIVE_BE",
        "entry_id": entry_id,
        "bank": bank,
        "proposed_value": value,
        "source": BE_SCOPE_SOURCE,
        "exact_native_record_ids": sorted(set(witnesses)),
        "classification": "EXCLUSIVELY_EXACT_NATIVE_REFERENCE_ONLY_CATALOG",
        "disposition": "NO_ASSERTION_CURRENT_DOMAINS_UNCHANGED",
    }

def compact_scaffold(scaffold: dict, bank: str) -> dict:
    """Project only the wire view along exact approved constraint connectivity.

    Guard dependencies participate in the graph even when blocked or excepted.
    All surviving domains and actual context remain. Omitted proofs and tables
    are identified by deterministic hashes; the complete original request stays
    the replay authority and is never rewritten by this view.
    """
    import copy
    import hashlib
    import json

    def digest(value):
        encoded = json.dumps(value, sort_keys=True, ensure_ascii=False, separators=(",", ":"), allow_nan=False)
        return hashlib.sha256(encoded.encode("utf-8")).hexdigest()

    connected = {bank}
    rules = scaffold["approved_relations"]
    while True:
        expanded = connected | {
            name
            for rule in rules
            if connected.intersection(rule["banks"] + rule["absent_evidence"])
            for name in rule["banks"] + rule["absent_evidence"]
        }
        if expanded == connected:
            break
        connected = expanded
    selected, omitted = [], []
    for rule in rules:
        relevant = bool(connected.intersection(rule["banks"]))
        if rule.get("requested_component") is not relevant:
            raise ValueError("INVALID_MODEL_SCAFFOLD_COMPONENT")
        (selected if relevant else omitted).append(rule)
    rule_ids = {rule["rule_id"] for rule in selected}
    proofs, omitted_proofs = [], []
    for receipt in scaffold["proof_trace"]:
        ids = set(receipt.get("rule_ids", ()))
        if "rule_id" in receipt:
            ids.add(receipt["rule_id"])
        relevant = receipt["kind"] == "INFERENCE_SCOPE" or receipt.get("bank") in connected or bool(ids & rule_ids)
        (proofs if relevant else omitted_proofs).append(receipt)
    data = copy.deepcopy(scaffold)
    data.update(
        {
            "format": SCAFFOLD_VIEW_FORMAT,
            "approved_relations": copy.deepcopy(selected),
            "proof_trace": copy.deepcopy(proofs),
            "component_banks": sorted(connected),
            "selection": "REQUESTED_BANK_TRANSITIVE_APPROVED_RULE_AND_GUARD_DEPENDENCIES",
            "inference_scope": "RETAINED_INFERENCE_SCOPE_RECEIPT_DESCRIBES_FULL_CLOSURE",
            "full_scaffold_sha256": digest(scaffold),
            "omissions": {
                "code": "OUTSIDE_REQUESTED_APPROVED_CONSTRAINT_COMPONENT",
                "approved_relation_count": len(omitted),
                "approved_relations_sha256": digest(omitted),
                "proof_receipt_count": len(omitted_proofs),
                "proof_receipts_sha256": digest(omitted_proofs),
                "semantics": "OMITTED_IS_NOT_ZERO_OR_UNAPPROVED",
            },
        }
    )
    return data


def model_input(payload: dict) -> dict:
    """Remove the null placeholder, which completion models otherwise copy.

    The original request retains every native record for replay. The wire view
    reports schema-based omissions and full-record hashes, never truncates to a
    context window, and never turns an unrequested coordinate into output.
    """
    import copy

    if payload.get("format") != "gse.bank-request/2" or payload.get("bank") not in BANKS:
        raise ValueError("INVALID_MODEL_REQUEST")
    scaffold = payload.get("scaffold")
    if (
        type(scaffold) is not dict
        or scaffold.get("format") != "gse.symbolic-scaffold/1"
        or type(scaffold.get("domains")) is not dict
        or scaffold["domains"].get(payload["bank"]) != payload.get("allowed_values")
        or type(scaffold.get("approved_relations")) is not list
        or type(scaffold.get("proof_trace")) is not list
        or type(scaffold.get("context")) is not dict
    ):
        raise ValueError("INVALID_MODEL_SCAFFOLD")
    data = copy.deepcopy(payload)
    data.pop("fill", None)
    data["scaffold"] = compact_scaffold(data["scaffold"], data["bank"])
    if data.get("observations"):
        data["evidence"] = compact_candidate_links(evidence_view(data.pop("observations"), data["bank"]))
    contract = protocol_contract()
    bank = data["bank"]
    contract.pop("negative_poles")
    contract["coordinate"] = contract.pop("coordinates")[bank]
    return {**contract, "input": data}

def _select_entries(conn, entry_ids, banks, limit, visited=frozenset(), *, frequencies=None):
    """Rank unvisited definitions using a bounded heap, never a mutable frontier.

    A later definition can finish before an earlier one, and accepted values
    change a definition's priority key. A cursor cannot prove either one visited.
    """
    requested = set(entry_ids or ())
    found, candidates = set(), []

    def rows():
        for entry, code, payload, lemma in conn.execute(
            "SELECT d.entry_id,d.code,d.domains,l.lemma FROM definition_states d JOIN lexemes l ON d.lexeme_id=l.id"
        ):
            if entry_ids is None and entry in visited:
                continue
            if entry_ids is not None and entry not in entry_ids:
                continue
            if entry_ids is not None:
                found.add(entry)
            domains = _read_json(payload)
            remaining = [len(domains[bank]) for bank in banks if len(domains[bank]) > 1]
            if entry_ids is None:
                if code != "PARTIAL" or not remaining:
                    continue
            known = sum(len(domain) == 1 for domain in domains.values())
            residual_size = min(remaining, default=4)
            first = residual_size if frequencies is None else (-frequencies.get(lemma.casefold(), 0), residual_size)
            key = (first, -known, entry)
            yield key

    if entry_ids is None:
        candidates = heapq.nsmallest(limit + 1, rows())
        return tuple(candidates[:limit]), len(candidates) > limit
    else:
        candidates = sorted(rows())
        if requested - found:
            raise ValueError("UNKNOWN_COMPLETION_DEFINITION")

def _scaffold(
    resolution: Resolution, relations: tuple[Relation, ...], context: dict[str, str] | None, bank: str
) -> dict:
    """Snapshot the actual closure, retaining rule dispositions and proof data.

    All domains and proofs are context, not requested output. Approved tables
    are preserved even when skipped or locally excepted; only ACTIVE tables
    constrain this definition. Candidate tables never become model authority.
    """
    if type(relations) is not tuple or any(not isinstance(rule, Relation) for rule in relations):
        raise ValueError("invalid_request_relations")
    context = {} if context is None else context
    if type(context) is not dict or any(type(k) is not str or type(v) is not str for k, v in context.items()):
        raise ValueError("invalid_request_context")
    by_id = {}
    for rule in relations:
        rule.__post_init__()
        if rule.rule_id in by_id or not set(rule.banks + rule.absent_evidence) <= resolution.domains.keys():
            raise ValueError("invalid_request_relations")
        by_id[rule.rule_id] = rule
    active, excepted, skipped, referenced = set(), set(), {}, set()
    for receipt in resolution.trace:
        ids = set(receipt.get("rule_ids", ()))
        if "rule_id" in receipt:
            ids.add(receipt["rule_id"])
        referenced.update(ids)
        if receipt["kind"] in {"JOINT_CHECK", "SOLVER_LIMIT"}:
            active.update(ids)
        elif receipt["kind"] == "CONDITIONAL_EXCEPTION":
            excepted.update(ids)
        elif receipt["kind"] == "RELATION_SKIPPED":
            skipped[receipt["rule_id"]] = receipt["reason"]
        elif receipt["kind"] == "EVIDENCE_GUARD" and receipt["status"] == "BLOCKED":
            skipped[receipt["rule_id"]] = receipt["reason"]
    if not referenced <= by_id.keys():
        raise ValueError("missing_request_relation_context")
    connected = {bank}
    approved = tuple(rule for rule in relations if rule.approved)
    while True:
        expanded = connected | {
            name
            for rule in approved
            if connected.intersection(rule.banks + rule.absent_evidence)
            for name in rule.banks + rule.absent_evidence
        }
        if expanded == connected:
            break
        connected = expanded
    records = []
    for rule in sorted(approved, key=lambda item: item.rule_id):
        if rule.rule_id in excepted:
            disposition, reason = "EXCEPTED_FOR_THIS_DEFINITION", "CONDITIONAL_EXCEPTION"
        elif rule.rule_id in skipped:
            disposition, reason = "BLOCKED", skipped[rule.rule_id]
        elif rule.rule_id in active:
            disposition, reason = "ACTIVE", "SYMBOLIC_CLOSURE"
        else:
            raise ValueError("missing_request_rule_proof")
        guard_matches = all(context.get(key) == value for key, value in rule.guards)
        if (disposition == "ACTIVE" and not guard_matches) or (reason == "GUARD_MISMATCH" and guard_matches):
            raise ValueError("inconsistent_request_guard_context")
        records.append(
            {
                **asdict(rule),
                "disposition": disposition,
                "reason": reason,
                "requested_component": bool(connected.intersection(rule.banks)),
            }
        )
    return _json_copy(
        {
            "format": "gse.symbolic-scaffold/1",
            "context": dict(sorted(context.items())),
            "domains": {name: sorted(values) for name, values in sorted(resolution.domains.items())},
            "approved_relations": records,
            "proof_trace": resolution.trace,
            "relation_semantics": "ONLY_ACTIVE_TABLES_CONSTRAIN_THIS_DEFINITION",
            "proof_semantics": "SYMBOLIC_JUSTIFICATION_NOT_ADDITIONAL_MODEL_OUTPUT",
        }
    )

def complete_bank(
    request: BankRequest,
    banks: tuple[str, ...],
    assertions: tuple[Assertion, ...],
    relations: tuple[Relation, ...],
    transport: Callable[[dict, dict], str],
    context: dict[str, str] | None = None,
    *,
    evidence_banks: tuple[str, ...] = (),
    domain_restrictions: tuple[DomainRestriction, ...] = (),
) -> Completion:
    """Validate freshness, obtain one ruling, then propagate before admitting it.

    Inputs are never mutated. Invalid caller-supplied engine inputs raise the
    engine's ValueError rather than being mislabeled as a model/network failure.
    """
    current = resolve_dictionary(
        banks, assertions, relations, context, evidence_banks=evidence_banks, domain_restrictions=domain_restrictions
    )
    try:
        fresh = build_request(
            request.entry_id,
            request.bank,
            current,
            request.observations,
            definition=request.definition,
            relations=relations,
            context=context,
            request_format=request.request_format,
        )
        same = fresh.request_id == request.request_id and _request_id(request.payload()) == request.request_id
    except ValueError as exc:
        return Completion("STALE_REQUEST", None, current, {"reason": str(exc)})
    if not same:
        return Completion("STALE_REQUEST", None, current, {"reason": "changed_request_state"})

    try:
        raw = transport(fresh.payload(), fresh.output_schema())
    except Exception as exc:
        details = {"error_type": type(exc).__name__}
        if isinstance(exc, ModelTransportError):
            details["reason"] = exc.code
        return Completion("TRANSPORT_ERROR", None, current, details)
    try:
        value = _read_value(raw, fresh)
    except (ValueError, TypeError, RecursionError) as exc:
        return Completion("INVALID_OUTPUT", None, current, {"reason": str(exc)})
    if value is None:
        return Completion("ABSTAINED", None, current, {"request_id": fresh.request_id})

    from .scope_admission import model_scope_admission

    scope = model_scope_admission(fresh.entry_id, fresh.bank, value, fresh.observations)
    if scope["code"] == "SCOPE_UNJUSTIFIED":
        return Completion("SCOPE_UNJUSTIFIED", None, current, {"request_id": fresh.request_id, **scope})

    model = getattr(transport, "identity", getattr(transport, "model", "typed-residual"))
    if type(model) is not str or not model:
        model = "typed-residual"
    assertion = Assertion(fresh.bank, value, f"model:{model}", fresh.request_id, "model")
    resolved = resolve_dictionary(
        banks,
        assertions + (assertion,),
        relations,
        context,
        evidence_banks=evidence_banks,
        domain_restrictions=domain_restrictions,
    )
    previous_exceptions = {
        rule_id
        for record in current.trace
        if record["kind"] == "CONDITIONAL_EXCEPTION"
        for rule_id in record["rule_ids"]
    }
    new_exceptions = tuple(
        record
        for record in resolved.trace
        if record["kind"] == "CONDITIONAL_EXCEPTION" and set(record["rule_ids"]) - previous_exceptions
    )
    changed_known = {
        bank: {"before": value, "after": resolved.assignments.get(bank)}
        for bank, value in current.assignments.items()
        if resolved.assignments.get(bank) != value
    }
    if resolved.code == "CONFLICT" or new_exceptions or changed_known:
        return Completion(
            "CONTRADICTION",
