`REFERENCE_MANIFEST.json` pins **absolute paths into the shared checkout** (`~/Projects/gse/docs/program/…`). `check_program.py` therefore hashes the shared checkout's copies wherever it runs, including from the sibling repositories. Any change to `docs/program/` on this branch must be mirrored to the shared checkout until the branch is merged.

## Gate baseline

Source record IDs are portable: a root tag, the path within that root and the native locator, for example `nltk:verbnet/admire-31.2.xml#class=admire-31.2-1&member=love`. The run manifest keeps each file's machine path and hash. A build that reads the same sources through a different path reproduces the baseline byte for byte, which was checked by aliasing the NLTK corpus. When the ID format changed, every one of the 1,040 records matched the previous baseline once old IDs were mapped to new ones; nothing else changed.
