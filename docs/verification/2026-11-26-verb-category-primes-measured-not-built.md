# WordNet verb categories as prime content: measured, not built (2026-11-26)

Question: does a WordNet verb lexicographer category whose stated meaning is one prime's meaning carry that prime
to every synset filed there (verb.emotion "verbs of feeling" -> FEEL; verb.motion "verbs of walking, flying,
swimming" -> MOVE; verb.contact "verbs of touching, hitting, tying, digging" -> TOUCH)?

Stored values agree wherever the release decides the bank (FEEL 169/169, MOVE 2,735/2,735, TOUCH 520/520), but
much of that comes from the approved WordNet hierarchy roots, so it is not independent. verb.cognition (also
knowing) and verb.communication (also singing) do not name one prime and were not tested further.

Against NSM's verified verb explications (GW16, G12), with each verb's WordNet first sense:

* verb.contact -> TOUCH is refuted: GW16's kill (two explications) and dig contain no TOUCH; cut, grind, carve,
  hit, kick, put and throw do.
* verb.motion -> MOVE holds for crawl, swim, fly, push, sink and fall, but WordNet files non-motion and
  anti-motion senses under it: carry.v.29 (carry a number to the next column), cut.v.18 (stop filming),
  disband.v.01, freeze.v.01 (stop moving), stop.v.01, stay.v.02. Selecting them out by gloss would be a hand filter;
  the approved hierarchy roots (move.v.03, travel.v.01) already carry MOVE where the structure warrants it.
* verb.emotion has no verb explication on disk to test against.

Nothing is installed.
